Abbreviations used on this page

CVcross-validation — measuring a design by training on some folds and scoring on the fold held out, rotating the held-out fold
nested CVan inner cross-validation (to choose H) inside each outer fold (to judge the choice)
K / I / Houter fold / inner fold / hyperparameter set
H*the winning hyperparameter set of a round — best mean inner score
K1H2the mean inner score of set H2 in round K1 (one cell of the grid)
outer_score_Kthe judge-fold score of round K — the honest number for that round
e / bepoch / batch
F1the F1 score — harmonic mean of precision and recall; the metric fixed in Phase V
valthe validate rows of a run (inner: 800; judge: 2,000)
lr / bs / do / eplearning rate / batch size / dropout / epochs — the four numbers in each H set
